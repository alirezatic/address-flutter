# Home UI Polish v2

اصلاحات این بسته:

- بازگرداندن حس سه‌بعدی و فنری بازشدن منو
- اندازه ریسپانسیو دکمه منو:
  - موبایل: 56px
  - تبلت: 66px
  - دسکتاپ: 74px
- افزایش فونت بنر اصلی در وب
- افزایش فونت کارت‌های خدمات
- افزایش فونت و آیکون‌های منوی کناری
- حفظ بهینه‌سازی‌های حذف Blur و جلوگیری از بازسازی اضافی
